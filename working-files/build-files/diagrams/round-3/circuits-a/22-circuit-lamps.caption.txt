Figure N. The three warning lamps and the start feedback after the swap: each sensor reads into the DME, and the DME drives the cluster from X60004 pins 11, 1, 21 and 2. On an MS43 you move these four wires over from body X6011 pins 3 to 6; on an MS45.1, which sent the lamps over CAN, you add the three lamp wires new and move the start feedback only if X6011 pin 6 holds a wire. Code all three cluster switches to <code>nicht_aktiv</code> so the lamps work whatever software the DME runs, and use cluster pin 13 for the oil-pressure lamp: pin 14 is the K-bus.
